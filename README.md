# 03 Habit Tracker

## Run the project
1. Extract this ZIP file.
2. Open `index.html` in a modern web browser.
3. No installation or server is required.

## Files
- `index.html` — page structure
- `style.css` — responsive design
- `script.js` — application logic

## Notes
This is a standalone front-end implementation using HTML, CSS and JavaScript. Data that needs saving is stored locally in the browser where applicable. No external API, hosted backend, or database is configured.
